# Softonic Phishing login page

## Overview

This repository contains a simulated login page inspired by the Softonic website. It was developed as part of a cybersecurity educational project to demonstrate how phishing attacks imitate legitimate websites and to help students understand the techniques used by attackers in a controlled, authorized environment.

The project is intended exclusively for defensive cybersecurity training.

## Objectives

* Demonstrate how phishing websites mimic legitimate login pages.
* Study the structure and appearance of modern authentication interfaces.
* Understand how users can identify phishing attempts.
* Learn defensive measures against credential theft.
* Support cybersecurity awareness and ethical hacking education.

## Features

* Responsive login page interface
* HTML, CSS, and JavaScript implementation
* Client-side form validation
* Demonstration of phishing website appearance
* Suitable for cybersecurity laboratory exercises
* Easy to customize for security awareness demonstrations

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Learning Outcomes

After completing this project, I can :
* Recognize common characteristics of phishing websites.
* Understand how attackers imitate trusted login pages.
* Identify indicators of fraudulent web pages.
* Apply secure development and cybersecurity best practices.
* Improve awareness of credential protection techniques.
